# DemoBlaze Selenium Test Suite

Basic UI automation script for https://www.demoblaze.com that validates:

- Signup (positive + duplicate user negative case)
- Login (invalid credentials + valid credentials)
- Product display on homepage
- Category navigation (Laptops)
- Pagination to the last page
- Adding the last product to the cart
- Cart verification
- Checkout attempt on empty cart (negative case)
- Logout
